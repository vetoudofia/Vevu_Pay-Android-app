# Google Play listing assets

- `play-store-icon-512.png`: 512 × 512 px, opaque PNG.
- `feature-graphic-1024x500.png`: 1024 × 500 px feature graphic.
- `PLAY-STORE-LISTING.md`: draft title, short description, full description and remaining review checklist.

Phone screenshots have intentionally not been fabricated. They must be captured from the final, running Android build after the key screens and payment flows have been tested. Use real app screens and do not show real customer names, balances, phone numbers, virtual account details or transaction references in public screenshots.

Capacitor source assets for Android icon/splash generation are in the project-root `resources/` folder.
